Build a **luxury, cinematic, high-end roofing company website** for:

**Business Name:** JR BIX Roofing
**Location:** Clarksville, TN
**Primary CTA:** Call Now for Your Free Estimate
**Instagram:** @jr_bixroofing

The website must NOT look like a typical roofing contractor template.

The design should communicate:

**QUALITY • CRAFTSMANSHIP • PROTECTION • PRECISION • TRUST**

# GLOBAL ANIMATION LANGUAGE

Create a consistent motion system throughout the website.

Use:

* Framer Motion
* Scroll-triggered reveals
* Mask animations
* Clip-path reveals
* Image scaling
* Parallax
* Staggered typography
* Hover interactions
* Smooth transitions
* Magnetic button effects where appropriate

Use elegant easing such as:

`cubic-bezier(0.16, 1, 0.3, 1)`

Avoid:

* Excessive bounce
* Random movement
* Constant floating animations
* Huge rotations
* Cheap-looking effects
* Animating everything simultaneously

Every animation must have a purpose.
